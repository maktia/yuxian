# 看見・未見｜育賢國中 App（專案 yuxian）

育賢國中 7 年級資優班 採編課程「看見・未見」的 AI 智慧眼鏡學生 App 介面設計稿與手機原型。
3 堂課 × 45 分鐘｜湖水藍 ・ 圓潤立體 ・ 圓體字

## 這包裡面有什麼

- `index.html`　**手機原型**：手機外框裡直接點按鈕操作，左邊清單可跳到任一畫面
- `overview.html`　總覽：所有畫面、流程圖與規格一次看完
- 18 張 App 畫面：`Connect` `CourseCode` `Main` `Tasks` `Library` `AIPrompt` `NoteEdit` `Card` `Questions` `Interview` `Transcript` `Draft` `Scan` `Suggest` `InterviewSheet` `Pass` `UploadOk` `UploadFail`
- 流程圖：`FlowMap1`～`FlowMap4`（1920×1080，可直接放投影片）、`OpFlow`（純方框操作流程圖）
- 規格：`Modules`（大題結構，給工程師）、`CardLayout`（圖文卡 A4 版型）

## 怎麼放到 GitHub Pages

1. 到 <https://github.com/new> 開一個新的 repository，名稱打 `yuxian`，選 **Public**，**不要**勾 Add a README file，按 Create。
2. 在新 repo 的畫面點 **uploading an existing file**。
3. 把這個資料夾裡的**所有檔案**（不是資料夾本身）拖進去，按 **Commit changes**。
4. 進 **Settings → Pages**，Source 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，按 Save。
5. 等 1～2 分鐘，網址會是 `https://<你的帳號>.github.io/yuxian/`

> 這是介面原型，不是可以真的用的 App。畫面裡的照片是佔位圖示，按鈕只做了主要路線的連結。
